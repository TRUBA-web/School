# NEXUS OS

Personal productivity dashboard made with pure HTML/CSS/JS.

## Features
- Dashboard
- Tasks with priorities
- Calendar
- Notes
- Pomodoro Focus
- Statistics
- Quick links
- LocalStorage
- JSON export/import
- Responsive mobile UI
- PWA/offline cache

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Upload the files to a public GitHub repository, then:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
